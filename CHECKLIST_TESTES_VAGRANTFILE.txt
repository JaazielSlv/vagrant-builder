================================================================================
CHECKLIST DE TESTES - VAGRANT BUILDER
================================================================================
Objetivo: garantir que os VagrantFiles gerados pela aplicação sejam validos,
funcionais e possam ser usados com 'vagrant up' sem erros.

Nenhum arquivo do projeto foi modificado para gerar esta lista.

--------------------------------------------------------------------------------
COMO USAR
--------------------------------------------------------------------------------
1. Abra o Vagrant Builder no navegador (npm run dev ou build em producao).
2. Execute cada item abaixo, marcando [X] quando passar.
3. Sempre que gerar um VagrantFile, rode:
   - vagrant validate          (verifica sintaxe Ruby/Vagrant)
   - vagrant up --no-provision (verifica se as VMs sobem)
   - vagrant provision         (verifica se o provisionamento funciona)
4. Anote falhas e anexe capturas de tela ou logs.
